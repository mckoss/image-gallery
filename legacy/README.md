# The Image Gallery, 2004

These are the original files from `mckoss.com/jscript/SlideShow/`, as they
were in the 2012 snapshot of the old site
([mckoss/original-mckoss.com](https://github.com/mckoss/original-mckoss.com/tree/master/jscript/SlideShow)).
They are kept here unchanged, for history. They ran only in Internet
Explorer: each gallery's data was an `<XML>` "data island", and the
cross-fade used IE's `filters`.

| Folder | What it is |
| --- | --- |
| `default.htm` | The project page: features and screenshots |
| `LATEST/` | The last version of the player (`slideshow.js`, `util.js`), with two galleries: `sample.htm` (Whizmo and Gizmo, JerkQuest '03, Day 1) and `caravan.htm` |
| `1.0/` | Version 1.0 (2004-09-17): the distribution page, `template.htm`, `sample.xml`, and Mark Jennings' `2004-09-16 MJ` revision |
| `2004-11-19/` | The November 2004 version |
| `SampleSource/` | The Whizmo and Gizmo photos and their 40x40 `-T` thumbnails |
| `CaravanSource/` | Thumbnails for the Caravan gallery (its photos were on caravan.cessna.com) |
| `CVS.htm` | Notes on the team's CVS setup (November 2004) |

Left out: the Windows Designer app (`PhotoAlbum.exe`, which cropped the
photos and picked the thumbnails), the CVS checkout metadata, and the
sample's soundtrack (`VH.wma`, "Ventura Highway" by America), a
commercial recording.
